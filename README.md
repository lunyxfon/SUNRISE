# SUNRISE: сайт студии уличного танца

Статический сайт из 5 страниц: HTML + CSS + vanilla JS. Сборка, Node.js и установка зависимостей не нужны.

## Запуск проекта

### Способ 1. Просто открыть файл
1. Скачайте проект: на GitHub нажмите **Code → Download ZIP** и распакуйте архив
   (или `git clone`, если пользуетесь Git).
2. Дважды щёлкните `index.html`. Сайт откроется в браузере, переходы между страницами работают.

Так удобно быстро посмотреть сайт. Минус: видео YouTube и VK, вставленные через `<iframe>`,
часто не воспроизводятся из файла, открытого с диска. Для работы с видео используйте способ 2.

### Способ 2. Локальный сервер (рекомендуется для работы)
Выберите любой вариант и откройте в браузере адрес, который он покажет.

**VS Code + Live Server** (проще всего):
1. Откройте папку проекта в VS Code.
2. Установите расширение **Live Server** (вкладка Extensions, Ctrl+Shift+X).
3. Правой кнопкой по `index.html` → **Open with Live Server**.
   Страница откроется на `http://127.0.0.1:5500` и будет обновляться сама при каждом сохранении.

**Python** (обычно уже установлен на macOS и Linux):
```bash
cd путь/к/папке/SUNRISE
python3 -m http.server 8000
```
Откройте http://localhost:8000. Остановить сервер: Ctrl+C. На Windows вместо `python3` пишите `python`.

**Node.js** (если установлен):
```bash
cd путь/к/папке/SUNRISE
npx serve .
```
Откройте адрес из терминала, обычно http://localhost:3000.

### Способ 3. Опубликовать в интернете
Сайт статический, поэтому подойдёт любой хостинг, который отдаёт файлы.

**GitHub Pages** (бесплатно):
1. Убедитесь, что файлы сайта лежат в нужной ветке репозитория (обычно `main`).
2. В репозитории откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку с сайтом (например, `main`) и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт появится по адресу вида `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

**Netlify** (бесплатно, без Git): зайдите на https://app.netlify.com/drop и перетащите папку проекта в окно браузера.

**Обычный хостинг** (Timeweb, Beget, REG.RU и т. п.): загрузите все файлы и папки проекта
в корневую папку сайта (обычно `public_html`) через файловый менеджер панели или FTP.
Главной страницей станет `index.html`.

При публикации загружайте папку целиком вместе с `styles.css`, `script.js` и `images/`.

## Файлы
| Файл | Что внутри |
|---|---|
| `index.html` | Главная: логотип, H1, hero-фото, запись на пробное, преимущества |
| `about.html` | История, ценности, преподаватели, отзывы, группы |
| `directions.html` | 6 направлений: видео, описание, расписание, якорная навигация |
| `gallery.html` | Masonry-галерея, фильтры, лайтбокс |
| `prices.html` | Тарифы, «Как записаться», контакты, карта, CTA |
| `styles.css` | Все стили. Цвета и шрифты задаются переменными в начале файла |
| `script.js` | Меню, анимации при скролле, подсветка якорей, фильтры и лайтбокс |

Все файлы лежат в одной папке. Каждая страница подключает `styles.css` в `<head>` и `script.js` в конце `<body>`.

## Что заменить
Найдите в файлах `ЗАМЕНИТЬ` (Ctrl+Shift+F в VS Code): рядом с каждым плейсхолдером есть комментарий с подсказкой.

- **Telegram**: замените `https://t.me/ВАШ_КАНАЛ` во всех файлах (поиск с заменой по проекту).
- **Фото**: создайте папку `images/` и вставьте внутрь блока `<div class="ph">` тег `<img src="images/hero.jpg" alt="...">`. Картинка займёт весь блок; иконку и подписи можно удалить.
- **Видео** (`directions.html`): вставьте `<iframe>` YouTube/VK или `<video>` внутрь `.ph` — готовые шаблоны лежат в комментариях.
- **Галерея**: у каждой `<figure>` укажите категорию в `data-cat` (`concerts`, `training`, `backstage`, `team`).
- **Карта** (`prices.html`): вставьте iframe из Конструктора Яндекс Карт или Google Maps внутрь `.ph`.
- **Цвета и шрифты**: поменяйте переменные `--c-accent` (фиолетовый акцент), `--f-display`, `--f-body` и другие в начале `styles.css`.

Шапка и подвал повторяются на каждой странице. Если меняете меню или контакты, правьте все 5 файлов.
